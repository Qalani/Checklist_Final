# Zen Workspace — Impeccable Design Guide

## Design Context

### Users
Zen Workspace serves a broad audience: knowledge workers, students, creatives, personal life organizers, and small collaborative teams. Users come to it during focused work sessions, daily planning, and life management. The common thread: they want to feel in control and at ease, not overwhelmed. The interface should reduce cognitive load and create space for clear thinking.

### Brand Personality
**Calm · Clear · Composed**

The interface should feel like a well-organized desk in a quiet room — every element purposeful, nothing superfluous. Zen Workspace is not trying to be exciting; it is trying to be reliable, restorative, and trustworthy. Voice is understated: confident without boasting, helpful without being chatty.

Emotional goals: users should feel focused, uncluttered, and gently capable. Not impressed by the UI — *at home in it*.

Zen Workspace does not reference other apps. It should feel distinctly its own.

### Aesthetic Direction
- **Visual tone:** Minimal and refined. Generous whitespace. Soft, diffuse shadows. Rounded corners throughout. No sharp rectangles, no harsh drop shadows, no aggressive gradients.
- **Color:** The "Solace" palette — cool sky neutrals (Zen), tranquil teal (Sage), soft lavender (Warm). Four themes: Zen Light (default), Dawn Light, Midnight Dark, Forest Dark. Saturated color is used sparingly, only for primary CTAs and key accents.
- **Typography:** Inter, clean hierarchy. Headings are semibold at modest sizes — never shouty. Secondary text fades gracefully with reduced opacity rather than smaller size alone.
- **Depth:** Glassmorphism is used for overlays and sticky elements (`bg-surface/80 backdrop-blur-2xl`). Elevation via shadow scale (soft → medium → lift) communicates hierarchy without skeuomorphism.
- **Motion:** Subtle and composed. Fade, slide-up, and scale-in at short durations (0.2–0.4s). Framer Motion for staggered list entries and data transitions. Never decorative — motion confirms state changes or guides attention.
- **Anti-references:** Avoid anything that feels cluttered, aggressive, gamified, or corporate-sterile. No badge-heavy interfaces, no neon accents, no heavy drop shadows, no "enterprise dashboard" energy.

### Design Principles
1. **Compose, don't crowd.** Every element earns its place. Prefer whitespace over density. If something can be removed without loss, remove it.
2. **Color with restraint.** The Solace palette exists in balance. Sage is for primary actions, Warm is for secondary accents, Zen neutrals carry the rest. Never introduce new colors without system-level justification.
3. **Consistency over cleverness.** Reuse established patterns (rounded-2xl cards, p-6 padding, shadow-soft default). Predictability is a feature — users should be able to predict behavior before they interact.
4. **Motion serves meaning.** Animate only when it helps a user understand what changed or where to look. Honor `prefers-reduced-motion`. Never animate for decoration alone.
5. **Accessible by default.** WCAG AA contrast at minimum. Keyboard navigation always functional. Never convey meaning through color alone. Semantic HTML and ARIA labels are non-negotiable, not afterthoughts.

## Token Reference

### Color System (CSS Variables, RGB notation)
All colors are defined as raw RGB values for alpha compositing:
```css
/* Usage: rgb(var(--color-zen-500) / 0.8) */
--color-zen-500: 113 153 182;   /* Medium sky blue */
--color-zen-600: 82 126 160;    /* Deep blue */
--color-zen-900: 24 49 68;      /* Near-black blue */
--color-sage-500: 62 170 152;   /* Primary teal CTA */
--color-sage-600: 45 142 124;   /* Hover teal */
--color-warm-500: 132 116 206;  /* Soft lavender accent */
--color-warm-600: 109 93 182;   /* Deeper lavender */
```

### Shadow Scale
```
shadow-soft:   0 2px 8px rgba(0,0,0,0.04)    → Default for cards
shadow-medium: 0 4px 16px rgba(0,0,0,0.08)   → Hover elevation
shadow-lift:   0 8px 24px rgba(0,0,0,0.12)   → Modals, FABs, floating nav
```

### Core Patterns
- **Card:** `bg-surface rounded-2xl border border-zen-100 shadow-soft p-6`
- **Primary button:** `bg-sage-500 text-white hover:bg-sage-600 rounded-xl`
- **Secondary button:** `border border-zen-200/80 bg-surface/80 hover:border-zen-400 rounded-xl`
- **Sticky/Glass header:** `bg-surface/80 backdrop-blur-2xl border-b border-zen-100`
- **Page title:** `text-2xl font-semibold text-zen-900`
- **Body text:** `text-sm text-zen-700`
- **Muted text:** `text-xs text-zen-500`
